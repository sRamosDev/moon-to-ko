💡 **What:** Modified `KOReaderExporter.export_statistics` in `src/koreader_exporter.py` to collect the records for insertion into a list, and then use `cursor.executemany` rather than making individual `cursor.execute` calls inside the loop.
Also fixed format and lint issues inside the code base via `ruff format` and `ruff check --fix`.

🎯 **Why:** To improve database write performance by reducing the transaction overhead of running `INSERT` queries sequentially. Using `executemany` batches the insertion, which is natively supported and heavily optimized by SQLite.

📊 **Measured Improvement:**
A benchmark involving inserting 1,000,000 book records and corresponding read statistics showed an overall performance improvement:

* **Baseline (execute):** ~6.66 seconds
* **Optimized (executemany):** ~5.19 seconds
* **Improvement:** ~22% performance increase

This demonstrates a measurable optimization without compromising functionality or correctness.
