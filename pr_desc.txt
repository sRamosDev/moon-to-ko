🧹 [code health] Use set comprehension instead of set(list_comp)

🎯 **What:** Replaced `set([x for x in y])` with `{x for x in y}` in `src/koreader_exporter.py`.
💡 **Why:** `set([x for x in y])` evaluates the entire list comprehension into memory as a list, and then converts it to a set. Using `{x for x in y}` evaluates values directly into a set without the intermediate list allocation, improving efficiency and code readability.
✅ **Verification:** Ran formatting (`uv run ruff check` and `uv run ruff format`), and successfully ran the test suite (`uv run pytest`) verifying that the refactor doesn't introduce regressions.
✨ **Result:** A more readable and strictly more performant way to build the set of basenames.
